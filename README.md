# ワールド寺子屋プログラム 2026（第5回）ランディングページ

NPO法人 EdFuture の海外探究プログラム「ワールド寺子屋プログラム」第5回の募集LP。
高校生が自分の問いを持って渡米し、現地校で学び、自分でアポを取って人に会いに行く 10〜14 日間のプログラムを案内する。

## 動かし方

ES モジュールを使うので、file:// では動かない。適当なサーバーで配信する。

```bash
python3 -m http.server 9070
# → http://127.0.0.1:9070/
```

## つくり

依存パッケージなし。素の HTML / CSS / ES モジュールだけで書いてある。

| 場所 | 中身 |
|---|---|
| `index.html` | 全セクション。1ファイル |
| `css/` | `base` 土台 ／ `fv` ファーストビューと幕 ／ `sections` 各章 ／ `spiral` 流れの螺旋と3プログラム ／ `kifu-parity` 寄付LPと揃えた部分 |
| `js/main.js` | 起動と結線。スクロール進捗・章の色・各UIの呼び出し |
| `js/spiral.js` | 応募から帰国までの7段階を螺旋に並べる（CSS 3D。ライブラリ不使用） |
| `js/door.js` | 最終CTAの扉（WebGL2。生で書いてある） |
| `js/eye.js` | ファーストビューの目（WebGL2） |
| `js/mascot.js` | マスコットのリグ。瞳・まぶた・口・腕を動かす |
| `js/ui.js` | タブ・FAQ・出現・カウントアップ・声カードの自動送りなど |
| `fonts/` | 自己ホストのサブセット。`build_fonts.py` がページの文字だけを集めて作る |

### ファーストビューの曲線

支給されたデザイン画像の輪郭を1列ずつ実測し、6次多項式に当てはめてから3次ベジエ9本に置き直して
SVG マスクにしてある。元画像との差は上1px・下2px。縦横比を保ったまま拡大するので、
スクロールで開いても形は崩れない。

## 版番号（キャッシュ対策）

**版を上げるときは必ず `bump.py` を使う。**

```bash
python3 bump.py           # 今日の日付＋連番で自動採番
python3 bump.py 20260907  # 明示指定
```

HTML のリンク・`modulepreload`・**JS どうしの import** の全部に同じ番号を配る。
HTML だけ上げると、ブラウザが古い `ui.js` を掴んだまま新しい `main.js` を読み、
存在しない名前を import した瞬間に全 JS が止まって「ページが開けない」状態になる。

フォントは `fonts/build_fonts.py` が woff2 の中身のハッシュを URL に付ける。
文字を足したら作り直す（ページを `http://127.0.0.1:8961` で配信した状態で実行）。
